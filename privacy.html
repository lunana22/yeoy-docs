구독포켓(Subs Pocket) 개인정보처리방침

최종 업데이트: 2026-07-20 시행일: 2026-06-26

구독포켓(이하 "앱")는 사용자의 개인정보를 소중히 여기며, 최소한의 정보만을 처리합니다. 본 앱은 개발자가 운영하는 서버나 앱 자체 계정이 없으며, 데이터는 사용자 기기 내부에 저장되고, 사용자가 원할 때만 사용자 본인의 클라우드(iCloud 또는 Google Drive) 로 백업·동기화됩니다. 개발자를 포함한 제3자는 사용자의 데이터에 접근할 수 없습니다.

1. 수집·저장하는 정보

본 앱은 사용자가 직접 입력한 다음 정보를 사용자 기기 내부(로컬 저장소) 에 저장합니다.

  • 구독 정보: 이름, 금액, 통화, 결제 주기, 결제 기준일, 메모
  • 구독 로고: 사용자가 선택한 사진(작게 리사이즈되어 기기에 저장) 또는 이미지 URL
  • 앱 설정: 표시 통화, 목록 레이아웃, 알림 설정, 동기화 설정

위 정보는 개발자 서버로 전송되지 않으며(개발자 서버가 존재하지 않습니다), 사용자가 클라우드 동기화를 켠 경우에만 아래 6항에 따라 사용자 본인의 클라우드 계정에 사본이 저장됩니다.

2. 수집하지 않는 정보

본 앱은 다음을 수집하지 않습니다.

  • 이름, 이메일, 전화번호 등 회원 식별 정보 (앱 자체 계정·회원가입 없음)
  • 위치 정보
  • 광고 식별자 / 사용 분석 / 추적(Tracking)
  • 연락처, 통화 기록, 기타 기기 데이터

Google Drive 백업을 위해 Google 계정으로 로그인하는 경우에도, 앱은 백업에 필요한 접근 권한(토큰)만 사용하며 Google 프로필 정보(이름·이메일 등)를 수집·저장·전송하지 않습니다.

3. 기기 권한 사용

권한 용도 비고
사진 라이브러리 구독 로고로 쓸 사진 선택 선택한 사진만 기기에 저장, 외부 전송 없음
알림 결제일 사전 리마인더(로컬 알림) 기기 내에서만 예약·표시, 외부 전송 없음

카메라·마이크·위치 등 다른 권한은 요청하지 않습니다.

4. 네트워크 사용

본 앱은 다음 목적에 한해 인터넷에 접속합니다.

  • 환율 정보 조회: 통화 환산 표시를 위해 공개 환율 API(open.er-api.com)에서 환율 데이터를 받아옵니다. 요청 시 표준 네트워크 정보(예: IP 주소)가 해당 서비스에 전달될 수 있으나, 앱이 사용자의 구독 내용이나 식별 정보를 함께 보내지는 않습니다.
  • 구독 프리셋 목록 조회: 추천 서비스 목록(이름·색상·로고)을 원격 파일에서 받아올 수 있습니다. 이 과정에서도 사용자 정보는 전송되지 않습니다.
  • 클라우드 백업/동기화(선택): 사용자가 동기화를 켠 경우, 구독 데이터가 사용자 본인의 클라우드 계정(6항)으로 전송됩니다.

5. 데이터 보관 및 삭제

  • 데이터는 기본적으로 사용자 기기에만 저장되며, 앱을 삭제하면 기기 내 데이터도 함께 삭제됩니다.
  • 클라우드 동기화를 사용한 경우, 사용자 본인의 클라우드에 저장된 백업은 앱 삭제 후에도 남을 수 있습니다. 삭제 방법은 6항을 참고하세요.
  • 앱 내 "내보내기" 기능으로 사용자가 직접 데이터를 JSON 파일로 저장/공유할 수 있으며, 해당 파일의 보관·관리 책임은 사용자에게 있습니다.
  • 개발자는 사용자의 데이터를 보관하지 않으므로, 개발자에 대한 별도의 삭제 요청 절차가 필요하지 않습니다.

6. 클라우드 백업/동기화 (선택 기능)

동기화는 기본적으로 꺼져 있으며, 사용자가 켠 경우에만 동작합니다. 어느 방식이든 데이터는 사용자 본인의 클라우드 계정에만 저장되며, 개발자는 접근할 수 없습니다.

  • iCloud (iOS): 사용자의 Apple 계정에 연결된 iCloud 키-값 저장소에 저장됩니다. Apple의 보안·약관이 적용됩니다. 삭제: 앱에서 동기화를 끄고, iOS 설정의 iCloud 관리에서 앱 데이터를 삭제할 수 있습니다.
  • Google Drive: Google 계정 로그인 후, Drive의 앱 전용 숨김 폴더(appDataFolder) 에만 저장됩니다. 앱은 이 폴더 외의 Drive 파일에 접근할 수 없습니다(권한 범위: drive.appdata). 삭제: 앱에서 동기화를 끄거나, Google Drive 설정 → 앱 관리에서 "숨겨진 앱 데이터 삭제"로 제거할 수 있습니다.

7. 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공·공유·판매하지 않습니다.

8. 아동의 개인정보

본 앱은 만 14세 미만(또는 거주 국가 기준 아동)을 주 대상으로 하지 않으며, 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

9. 보안

기기 내 데이터는 운영체제의 보안(잠금화면·저장소 보호 등)으로, 클라우드 백업은 Apple/Google 계정의 보안(암호·2단계 인증 등)으로 보호됩니다.

10. 방침 변경

본 방침은 법령·서비스 변경에 따라 개정될 수 있으며, 개정 시 앱 또는 본 페이지를 통해 고지합니다.
